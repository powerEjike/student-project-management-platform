# Department workspaces

ProjectTrack serves multiple departments at https://projecttrack-departments.web.app/. The existing Biochemistry address continues to work with the same records.

## Set up a department

1. In Super Admin → Workspace → Departments & staff, create the department.
2. Open **Customize department** on its card. Save its default programme, colour and welcome line. These do not change existing student programmes or project records.
3. Prepare/provision staff through the existing trusted staff onboarding process. Assign an HOD and lecturers to this department in the staff directory. Five lecturers is a suggested starting point, not an access requirement.
4. In **Academic sessions**, set that department's current session. Configure its programme milestone template before supervisors approve topics.
5. Copy the department's student link from its card. A link preselects the department; it never grants access or bypasses administrator approval.

## HOD handover

In Workspace, expand **Department setup & student records**. The HOD can copy the student link, view the active lecturer list and upload a CSV/Excel roster for their own department. Review the programme, current session, admission session and level before importing. Existing student identities are skipped. Final-year records become available in the allocation list; lower levels use attendance.

Students register using their department link and verify their email. The Super Admin reviews their identity against the appropriate roster and approves access. HODs cannot approve student accounts, create departments or change staff permissions.

## Separation

Department IDs continue to scope students, projects, staff chat, attendance and archives. HOD roster-import receipts now permit that department's HOD as well as Super Admin; receipts remain immutable. Customization is Super Admin-only and accepts a bounded programme/welcome string and a six-digit hex colour. No existing department/student/account is migrated by this release.

Billing remains disabled. Shared original file storage and automatic email delivery remain outside this release.
